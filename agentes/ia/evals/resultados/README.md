# Resultados de las evaluaciones

Un archivo por pasada: `AAAA-MM-DD.md`, con la puntuación de cada caso, el total
sobre el máximo y la comparación con la anterior.

Si una pasada baja respecto a la anterior, el entrenador **revierte** el último
cambio del prompt y lo anota. Esa es la regla que impide que "entrenar" sea ir
empeorando sin darse cuenta.
