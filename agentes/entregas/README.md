# Entregas

Material terminado que no va directo al código: textos para pegar en otro sitio,
decisiones razonadas, especificaciones, borradores para revisar.

Cada archivo empieza diciendo **dónde va** y **qué hacer con él**. Cuando ya
esté aplicado, se mueve a `aplicado/` o se borra: lo que queda aquí es lo que
está pendiente de llevar.
